# New GRU Seed Blend Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Evaluate whether a user-run CNN-GRU seed-21 candidate can improve current best through conservative blending.

**Architecture:** The user runs the GPU-heavy CNN-GRU generation command manually. The assistant then uses CPU-only blend and distribution scripts to evaluate low-weight blends into `w25`.

**Tech Stack:** Python, PyTorch for user-run model generation, pandas/NumPy blend scripts, `AGENTS.md`.
